# 🔒 Material privado del docente

Esta carpeta contiene:

- `teacher-guide.md` — guía con todos los problemas intencionales,
  principios que violan, evidencia, impacto, severidad y soluciones.
- `screenshots/` — capturas de la interfaz para usar en clase o
  material impreso.

**No debe compartirse con los estudiantes** antes de la actividad.

Para la versión pública del repositorio, estos archivos deben
permanecer en `docs/` pero **sin acceso al público** (por ejemplo,
repositorio privado o rama separada).

Si el repositorio es público, **borrar** o **mover** estos archivos
antes de compartir el enlace con los estudiantes.
